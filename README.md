# 座椅传感器 × micro:bit 久坐提醒器

**版本：v1.0.0（单机版）**

利用汽车级薄膜压力座椅传感器（DJ7021-5.3-11 接口）配合 micro:bit，检测是否有人坐在座椅上，超过设定时间后通过 LED 矩阵提醒起身活动。

---

## 工作原理

- 传感器是**常开（NO）开关**：无人坐时触点断开，有人坐时触点闭合（电阻 ≤100Ω）
- 利用 micro:bit P1 的**内部下拉电阻**（无需外接元件）把传感器当成"按键"：有人坐 → P1=1，无人坐 → P1=0
- 倒计时到阈值后：全屏骷髅 1 Hz 闪烁，每 5 分钟再叠加一次「大叉 X 闪 3 次 + 箭头」强提醒
- 超时后用户站起来：显示小人走路动画作为冷却，**冷却时长 = 实际坐的时长 × 20%**
- **未超时**短暂离开（≤30 秒）：画面**冻结在离开瞬间**，回来接续计时；超过 30 秒或已超时后离开：进入冷却流程

---

## 接线

- 传感器**红线** → micro:bit **3.3V**
- 传感器**黑线** → micro:bit **P1**（启用内部下拉电阻）
- 极性无要求：若 P1 一直读到 0，把两根线对调

完整示意图、座椅剖面、BOM 见 git 历史版本。

## 按键操作

| 按键 | 功能 |
|------|------|
| **A 键** | 循环切换阈值 **15 / 30 / 45 / 60 分钟**，LED 滚动显示新数值；同时清空当前计时与冷却 |
| **B 键** | 手动重置：先显示笑脸 0.5 秒，再滚动显示当前挡位，最后清屏 |
| 上电 | 自动启动，显示 ✓ 后滚动显示当前阈值（默认 45 分钟） |

## 状态显示

### 状态机

| 状态 | LED 显示 | 触发进入 / 离开 |
|------|---------|----------------|
| 上电 | ✓ → 滚动显示当前阈值 | 启动 |
| 空闲 | 灭 | 无人坐 |
| 计时中 | 接力式 1 Hz 闪烁进度条（25 颗 LED 均分总时长） | 坐下 → 离开（未超时短暂离开则冻结画面） |
| 超时 | 全屏骷髅 1 Hz 闪烁（无限期） | 达到阈值 → 离开 |
| 冷却 | 小人走路动画（两帧交替，200ms 一帧），时长 = 实际坐 × 20% | 超时后站起来 → 冷却结束 / 坐下 |

A 键 / B 键在任意状态下都立即生效（切换阈值或完全重置）。

### 进度条规则

- 总时长平均分配给 25 颗 LED，每颗分到的工作时长 = 总毫秒数 ÷ 25
- 每颗 LED 在自己的时段内持续 1 Hz 闪烁（亮 0.5s / 灭 0.5s），闪烁结束后立刻转常亮
- 任意时刻只有 1 颗正在闪烁，之前完成的常亮，未开始的灭
- 填充方向：从下往上、每行从左到右
- 总时长结束：全部 25 颗常亮，进入超时分支

各阈值下每颗 LED 的工作时长：

| 阈值 | 每颗工作时长 | 闪烁次数 |
|------|------------|---------|
| 15 分钟 | 36 秒 | 36 |
| 30 分钟 | 72 秒 | 72 |
| 45 分钟 | 108 秒 | 108 |
| 60 分钟 | 144 秒 | 144 |

### 超时与冷却流程

1. **大叉叠加**（每 5 分钟一次）：X 闪 3 次 + 箭头 1 次，期间暂停骷髅闪烁
2. **持续骷髅**：`Image.SKULL` 1 Hz 闪烁，直到用户站起来
3. **冷却走路动画**：用户站起后开始，时长 = 实际坐的总时长 × 20%（如 45 分钟准时站起 → 冷却 9 分钟；坐满 60 分钟才起 → 冷却 12 分钟）
4. **冷却结束**：黑屏等待，等待坐下或按键
5. **坐下可随时中断冷却**，重新开始计时

### 显示总表

| 状态 | LED 显示 |
|------|---------|
| 上电 | ✓ → 滚动显示当前阈值 |
| 无人坐（未超时短暂离开） | 进度条冻结在离开瞬间 |
| 计时中 | 接力式 1 Hz 闪烁进度条 |
| 刚达到阈值 | X 闪 3 次 + 箭头 1 次 + 持续全屏骷髅闪烁 |
| 每 5 分钟叠加提醒 | 大叉 X 闪 3 次 + 站立箭头 |
| 超时后站起来 | 小人走路动画（时长 = 实际坐 × 20%） |
| 冷却结束 | 黑屏，等待坐下或按键 |
| A 键切换阈值 | 滚动显示新阈值，清空计时与冷却 |
| B 键手动重置 | 笑脸 0.5 秒 + 滚动显示当前挡位 + 清屏 |

## 烧录

1. 用 USB 数据线把 micro:bit 连接到电脑
2. 打开 [https://python.microbit.org](https://python.microbit.org) 或本地 Mu / Thonny
3. 把 `main.py` 内容全部粘贴进去，Flash 烧录
4. 烧录完成后，micro:bit 显示 ✓ 并滚动显示当前阈值（默认 45）
5. 拔掉 USB，接电池盒，把传感器垫在座椅蒙皮与海绵之间

## 调试 / 故障排查

| 现象 | 可能原因 | 解决办法 |
|------|---------|---------|
| 一直读到 0 | 传感器两根线接反 | 红/黑线对调 |
| 一直读到 1 | 3.3V 短路 / 传感器线破皮 | 万用表测传感器电阻：空载 >1MΩ，坐上 <100Ω |
| 坐下/起立时频繁误触发 | 抖动 | 调大 `DEBOUNCE_COUNT`（如改为 3 或 5） |
| 坐 1 小时不提醒 | 阈值档位选错 | 按 A 键确认当前阈值；用 REPL 看 `print(running_time())` |
| 闪烁节奏不合适 | 1 Hz 太快/太慢 | 调整 `draw_progress()` 里的 `// 500`（保持 SAMPLE_MS=100） |
| 想临时测 1 分钟就提醒 | 改阈值 | 编辑 `THRESHOLDS = [1, 2, 5]` 测试后改回 |

实时调试：在 `while True` 开头加 `print("P1=", pin1.read_digital())`，用 Mu 的 REPL 或 Thonny 串口监视器查看读数。
