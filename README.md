# sitdetecter — 久坐提醒器

基于 BBC micro:bit 与薄膜压力传感器的久坐检测与提醒装置，使用 MicroPython 编写。**v2.0.0** 新增开机音量选择与音频提醒（`music` 库）。

> 版本：**v2.0.0（单机版）**  
> 平台：**MicroPython on BBC micro:bit**

---

## 功能特性

- 🪑 **久坐检测**：通过座椅压力传感器实时检测是否有人坐下
- 🔊 **开机音量设置**：开机进入音量调节模式，**A 键**切换音量档位（0 / 50 / 100 / 150 / 200 / 250），进度条显示当前音量，**B 键**确认进入主程序
- ⏱️ **可调阈值**：5 档循环切换（**0.1 / 15 / 30 / 45 / 60 分钟**），按 **A 键**循环（默认从 0.1 分钟 / 6 秒开始，便于快速测试）
- 📊 **接力式进度条**：5×5 LED 点阵显示久坐进度，每颗 LED 在自己的时段内 1 Hz 闪烁，结束后转常亮
- 💀 **超时强提醒 + 音效**：超时后大叉 `X` 闪 3 次（每次同步播放 `music.POWER_DOWN`），箭头 1 次，随后持续骷髅闪烁 + 440 Hz 提示音
- 🚶 **冷却奖励动画**：站起后显示小人走路动画，冷却时长 = 实际坐姿时长 × **20%**（坐 45 分钟 → 冷却 9 分钟；坐 60 分钟 → 冷却 12 分钟）
- 🔁 **短暂离开容差**：**30 秒内**回来会补偿计时，保持累计连续；超过 30 秒才算真正离开
- 🔄 **手动重置**：随时按 **B 键**清空计时与冷却状态，并播放 `music.BA_DING`
- 🛡️ **去抖动**：连续 **2 次**采样一致才认定状态变化，避免误触发

## 接线方式

| 传感器线 | micro:bit 引脚 | 备注 |
| --- | --- | --- |
| 🔴 红线（VCC） | **3.3V** | 电源正极 |
| ⚫ 黑线（信号） | **P1** | 程序里已启用内部下拉电阻 |

传感器为**常开型**：未受压时输出低电平，受压时输出高电平。代码首行的 `pin1.set_pull(pin1.PULL_DOWN)` 已确保默认下拉到低电平。

## 快速开始

1. **刷入 MicroPython 固件**：按 [micro:bit 官方指南](https://microbit.org/get-started/user-guide/python/) 将 MicroPython 固件刷入 micro:bit。
2. **连接设备**：用 USB 数据线把 micro:bit 连到电脑，会出现一个名为 `MICROBIT` 的 U 盘。
3. **烧录代码**：把仓库里的 `main.py` 复制到 `MICROBIT` 盘根目录（覆盖默认文件即可）。
4. **重启**：拔掉 USB 重连，或按 micro:bit 背面的 **RESET** 按钮，程序自动启动。
5. **首次启动流程**：
   - 进入**开机音量设置**模式
   - 按 **A 键**循环切换音量（0 / 50 / 100 / 150 / 200 / 250），进度条显示当前音量，每按一次播放 `BA_DING` 试听
   - 按 **B 键**确认音量，进入主程序，默认阈值 **0.1 分钟（6 秒）** 滚动显示

## 使用说明

### 开机音量设置

| 操作 | 按键 | 反馈 |
| --- | --- | --- |
| 切换音量档 | **A 键** | 进度条显示当前音量，播放 `BA_DING` |
| 确认音量 | **B 键** | 进入主程序，滚动显示默认阈值 0.1 |

音量档位：`[0, 50, 100, 150, 200, 250]`（`VOLUME_THRESHOLDS`），首次循环从 `volume_config_idx = 0`（音量 0）开始。`plot_bar_graph(volume, 250)` 用同样的接力式进度条把音量映射到 25 颗 LED。

### 按键与显示对照表（主程序）

| 操作 | 按键 / 行为 | 屏幕反馈 | 音效 |
| --- | --- | --- | --- |
| 切换阈值档位 | 按 **A 键** | 滚动显示新的分钟数（0.1 → 15 → 30 → 45 → 60 → 0.1 …） | 播放 `BA_DING` |
| 手动重置 | 按 **B 键** | 显示笑脸 😀 → 滚动显示当前阈值 | 播放 `BA_DING` |
| 坐下 | 传感器受压 | 进度条从底部开始接力式点亮 | — |
| 超时 | 坐姿时长 ≥ 阈值 | 大叉 `X` 闪 3 次 → 箭头 → 持续骷髅闪烁 | `X` 时播放 `POWER_DOWN`；骷髅闪烁时持续 440 Hz `pitch` |
| 站起（未超时 + 短暂离开） | 传感器释放 | 画面冻结在离开瞬间那颗 LED | — |
| 站起（真离开 / 已超时） | 传感器释放 | 小人走路动画（冷却期内） | `BA_DING`（`reset_progress`） |
| 冷却结束 | 冷却时长走完 | 黑屏，等待坐下或切换阈值 | — |

### 进度条规则

- 总时长被**均分到 25 颗 LED**，每颗分到 `阈值 ÷ 25` 毫秒
- **当前正在填充**的那颗 LED 按 **1 Hz 闪烁**（亮 0.5s / 灭 0.5s）
- **闪烁结束后**立即转常亮，作为累计进度的标记
- **填充方向**：从底部开始，每行从左到右（`LED_FILL_ORDER`）
- 开机音量设置也复用同一进度条函数（`plot_bar_graph(volume, 250)`）

### 冷却规则

- 冷却时长 = **实际坐姿时长 × 20%**（`COOLDOWN_RATIO`）
- 坐下立即取消冷却状态，无需等待
- 冷却期内显示小人走路动画，结束后保持黑屏

### 超时强提醒规则

- 首次超时：`X` 闪 3 次（每闪一次播放 `POWER_DOWN`）→ 箭头 → 持续骷髅闪烁（骷髅亮时 440 Hz `pitch`，灭时 `music.stop()`）
- 之后每 **5 分钟**（`WARN_REPEAT_MIN`）再叠加一次 `X` + 箭头 + 音效

## 工作原理

### 状态机概览

```
        ┌──────────────────────────────────────┐
        │        开机：音量设置循环             │
        │   A 切换音量 → 进度条显示 + 试听     │
        │   B 确认 → 进入主程序                │
        └──────────────────────────────────────┘
                          ↓
┌─────────┐  坐下(受压)   ┌──────────────┐  到阈值   ┌──────────────┐
│  空闲   │ ──────────────→│  正在倒计时  │──────────→│   超时提醒   │
│ (无人坐) │               │ (进度条填充) │           │(X+骷髅+音效) │
└─────────┘               └──────────────┘           └──────────────┘
     ↑                          │                          │
     │    站起(释放)             │       站起               │
     │                          ↓                          ↓
     │                  ┌──────────────┐          ┌──────────────┐
     │                  │  短暂离开    │          │  冷却(走路动画)│
     │                  │(冻结进度,30s)│          │  实际坐 × 20% │
     │                  └──────────────┘          └──────────────┘
     │                          │                          │
     │    超时或超过容差         │                          │
     └──────────────────────────┴──────────────────────────┘
```

### 关键设计

1. **去抖动**：传感器读数连续 `DEBOUNCE_COUNT` 次一致才切换 `stable_state`，避免坐下/站起瞬间的毛刺。
2. **短暂离开容差**：用户临时起身（如接电话、上厕所）不应重置进度。`frozen_elapsed_ms` 保存离开瞬间的累计时长，**30 秒内回来**则把离开时长补偿进 `sit_start_ms`，让累计时间保持连续；超过 30 秒才走真正离开流程。
3. **已超时后立即冷却**：超时提醒一旦触发，只要人离开就不再纠缠，立刻进入冷却动画。
4. **闪烁相位用墙钟驱动**：进度条用 `now_ms // 500` 取闪烁相位，短暂离开冻结时画面也能正确"闪烁"，而不是停在一个静态像素上。
5. **音频三档分工**：
   - `BA_DING`：状态切换提示（阈值切换、手动重置、清进度），轻柔
   - `POWER_DOWN`：超时警报，与 `X` 闪 3 次同步，强提醒
   - `pitch(440)` + `music.stop()`：骷髅闪烁亮灭同步发声 / 静音，提示持续存在

## 常见问题

**Q：代码里有音量设置吗？**  
A：有。`VOLUME_THRESHOLDS = [0, 50, 100, 150, 200, 250]` 是音量档位；开机进入音量调节循环，用 `set_volume()` 设置全局音量，`music` 库负责播放内置旋律与频率。

**Q：第一个阈值是 0.1 分钟吗？**  
A：是。`THRESHOLDS = [0.1, 15, 30, 45, 60]`（分钟），第一个值是 **0.1 分钟（6 秒）**，方便开发调试快速验证全流程。`config_idx = 0` 让开机默认从这一档开始。

**Q：micro:bit V1 没有蜂鸣器怎么办？**  
A：V1 需外接蜂鸣器到 `P0` 引脚并把 `import music` 替换成自己写的 beep 逻辑；V2 自带蜂鸣器，开箱即用。

**Q：怎么改成更长的默认值（比如 45 分钟）？**  
A：编辑 `main.py` 把 `THRESHOLDS` 改成 `[15, 30, 45, 60]`、`config_idx = 1`（默认 15 分钟）或改数组顺序。
